OpenProof provides a DPDP compliance platform for Indian businesses, offering tools to scan public websites for data protection gaps, assess consent and vendor management, fix issues with guided tasks, and generate audit‑ready evidence. The service includes automated checks for HTTPS, cookie consent, third‑party trackers, and supports data‑mapping, RoPA, grievance handling, and compliance reporting, helping companies meet Indian data protection regulations.

**Areas:** DPDP · Compliance · Indian Business · Data Protection · SaaS

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for OpenProof: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
